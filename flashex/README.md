# FlashEx

FlashEx prepares Arduino projects from a natural-language hardware description.

Run **FlashEx: Set Up Arduino Project** from the Command Palette, then enter a project description. The current implementation uses mock requirements for testing and installs the returned VS Code extensions, Arduino libraries, and Arduino board cores.

## Requirements

- Arduino CLI available on `PATH`
- VS Code or Arduino IDE 2.x

## Development

```bash
npm install
npm run compile
```
