Before you start

A small setup, clearly stated.

Supported environments

Windows, macOS, and Linux with VS Code or Arduino IDE 2.x.

Command line

Arduino CLI must be installed and available on your PATH.

AI access

FlashEx asks for a Google Gemini API key and stores it in the editor's secret storage.

Current release

Version 0.0.1. Review generated sketches before using them in production hardware.

Questions, answered

Know before you build.

What is FlashEx?

FlashEx is an open-source developer tool that turns a natural-language Arduino project description into a project folder, sketch, and dependency setup plan.

What does FlashEx require?

You need VS Code or Arduino IDE 2.x, Arduino CLI on your PATH, and a Google Gemini API key for AI-assisted project planning.

Which operating systems are supported?

The workflow is designed for Windows, macOS, and Linux environments that support VS Code or Arduino IDE 2.x.

Is generated code production-ready?

Generated sketches are starting points. Review, compile, test, and adapt every project before production or safety-critical use.
